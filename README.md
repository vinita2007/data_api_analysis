# Python Data & APIs Analysis Application

## Overview
A complete end-to-end Python data pipeline built as part of **Module 04: Python Data & APIs**[span_0](start_span)[span_0](end_span). It fetches live JSON data from a REST API, processes and cleans the dataset using **Pandas** and **NumPy**, generates a CSV analytical report, and visualizes key metrics using **Matplotlib** and **Seaborn**[span_1](start_span)[span_1](end_span).

## Key Features
- **REST API Integration:** Fetches and parses JSON payloads using Python's `requests` library[span_2](start_span)[span_2](end_span).
- **Data Cleaning & Manipulation:** Normalizes nested JSON into structured Pandas DataFrames, handles missing values, and computes summary statistics with NumPy[span_3](start_span)[span_3](end_span).
- **Automated Reporting:** Exports processed insights into `api_analysis_report.csv`[span_4](start_span)[span_4](end_span).
- **Data Visualization:** Generates a clean horizontal bar chart (`revenue_chart.png`) comparing performance metrics[span_5](start_span)[span_5](end_span).
